# ADMUS

Interactive advertising gallery, built as a static mobile-first site.

## Deploy
This repository can be deployed directly as a static site on Vercel, Netlify, or GitHub Pages.

## AdSense
Live AdSense requires an approved AdSense account and a real domain. Insert the publisher/ad-unit code provided by Google into the marked ad slots after approval. Do not use artificial refreshes, bots, incentivized clicks, or traffic intended solely to inflate ad impressions.
