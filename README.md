# ADMUS

Interactive advertising gallery, built as a static mobile-first site.

## Deploy
This repository can be deployed directly as a static site on Vercel, Netlify, or GitHub Pages.

## AdSense
Live AdSense requires an approved AdSense account and a real domain. Insert the publisher/ad-unit code provided by Google into the marked ad slots after approval. Do not use artificial refreshes, bots, incentivized clicks, or traffic intended solely to inflate ad impressions.

## Amazon connection mode

ADMUS currently works without Amazon Creators API credentials. The public shopping experience uses direct Amazon.in search/product links so users can see Amazon's current catalog, prices, and availability on Amazon itself. The site does not depend on an Amazon API key being present in the browser.

The Netlify function remains available as a server-side integration point for a future official Creators API connection. Amazon Associates requirements and current API access rules should be checked before enabling live Product Advertising Content.
